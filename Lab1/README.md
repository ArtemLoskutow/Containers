# Containers

Работа №1 посвящена знакомству с Docker. Самостоятельное приложение не разрабатывается: выполняются команды из методических материалов.

Изучение Docker возможно без дополнительных ресурсов.
Требуется исключительно работающий Docker и доступ к интернету для загрузки образов.
